# Resmi Balkon Elçisi

Bu yazılım, bir balkon çiçeği ile **devletler hukuku seviyesinde** diplomatik ilişki kurmak için tasarlanmıştır.

Sulama gecikmesi artık "unuttum" değildir. Sulama gecikmesi **nota konusudur**.

## Neden bu proje var?

Çünkü:

1. Sardunya özgürlüğü evrensel bir ilkedir.
2. Komşu balkonun fesleğeni çok kibirli bakıyor.
3. Birinin resmi evrak üretmesi gerekiyordu ve o biri bendim.

## Kurulum

```bash
python3 elci.py
python3 elci.py sardunya
python3 elci.py --arsiv
```

Üçüncü komut arşiv dipnotunu açar. Arşiv dipnotu hava durumu değildir. Belki de öyledir. Kimse sormasın.

## Protokol ilkeleri

- Çiçeğe bağırılmaz, nota yazılır.
- Toprak talebi insani yardım kalemidir.
- Rüzgâr tarafsız gözlemcidir.
- Kaktüs küserse görüşmeler askıya alınır.

## Sorumluluk reddi

Bu yazılım gerçekten çalışır. Çiçeğiniz cevap vermezse bu sizin suçunuz değildir; protokol çalışmıştır, muhatap sessiz kalmıştır.
